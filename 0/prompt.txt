implement Step 2: Unified Intermediate Representation (IR) Architecture
To satisfy "Do not duplicate the entire implementation for each format", use the Parser / Intermediate Representation (IR) pattern:

Both V1 (directory-based artifacts + legacy JSONL) and V2 (unified event-stream JSONL) parse into a shared, canonical SessionIR.

Unknown event types are stored in an open RawPayload / Attributes map without failing.

Incomplete transcripts produce a SessionIR marked with Partial: true rather than aborting.

┌──────────────────────────────────────┐       ┌──────────────────────────────────────┐
│       V1 Input (Legacy Files)        │       │       V2 Input (Unified JSONL)       │
│  .antigravity/artifacts/*.md         │       │  {"type":"artifact_update", ...}     │
│  .antigravity/execution.jsonl        │       │  {"type":"tool_call", ...}           │
└──────────────────┬───────────────────┘       └──────────────────┬───────────────────┘
                   │                                              │
                   ▼                                              ▼
